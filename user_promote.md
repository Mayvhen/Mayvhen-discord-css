# Centered Typing
A quick snippet that centers the typing indicator and hides the bouncing dots

Works best with MochaCord by @davidhifi 

Import (Quick CSS)
```css
@import url("https://raw.githubusercontent.com/Mayvhen/The-Witch-Repo/main/testcord/css/Centered-Typing/Centered-Typing.css");
```

Import MochaCord version (Quick CSS)
```css
@import url("https://raw.githubusercontent.com/Mayvhen/The-Witch-Repo/main/testcord/css/Centered-Typing/Centered-Typing-MochaCord.css");
```

Raw (if you want to download the theme)
```link
https://raw.githubusercontent.com/Mayvhen/The-Witch-Repo/main/testcord/css/Centered-Typing/Centered-Typing.css
```
