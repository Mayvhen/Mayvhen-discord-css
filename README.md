# discord-themes

A portfolio of Discord / TestCord CSS themes and tweaks, built by hand.

---

## Features

| Preview | Mod | What it does |
|---|---|---|
| <img src="https://github.com/Mayvhen/discord-themes/raw/main/media/Centered-Typing.gif" width="220" alt="Centered-Typing preview"> | [Centered-Typing](https://github.com/Mayvhen/Centered-Typing) | Centers typing indicator (`vc-typing-indicator`), hides dots (`.dots_b88801`), lifts indicator (`translateY(-4px)`), scales multi-line gap. Auth: Grande Sorciere `v1.0.4`. Works with MochaCord. |

---

@import url("https://raw.githubusercontent.com/Mayvhen/Centered-Typing/main/typing-centered.css");
