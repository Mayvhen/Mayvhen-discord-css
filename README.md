# Centered Typing

**Author:** Grande Sorciere  
**Version:** 1.0

Centers the typing indicator above chat, hides dot animation, shifts it slightly upward.

## Install — File

1. Download `typing-centered.css` from the latest release.
2. Copy it to `%APPDATA%\TestCord\themes` (or your TestCord themes folder).
3. Enable it in **Settings ▶ Themes**.

## Install — Online Theme (no download)

Paste this URL into **Settings ▶ Themes ▶ Enable Online Themes ▶ Add**:

```
https://raw.githubusercontent.com/GrandeSorciere/Centered-Typing/main/typing-centered.css
```

Then turn **Centered Typing** on.

## What it does

- Centers the "is typing" text horizontally.
- Removes the bouncing dot animation (`.dots_b88801`).
- Lifts the indicator up (`translateY(-30px)`).
